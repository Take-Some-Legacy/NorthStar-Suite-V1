## Summary
- Large Rust files >550 LOC: 64

## Pass order

1. **P0 runtime conductor split:** `runtime-host`, `engine-runtime`, gateway registry/service code.
2. **P1 assets/UI split:** asset catalog/browser UI, asset store, ListFile codec.
3. **P2 render provider split:** Vulkan renderer lib, GPU resources, render passes, debug overlay.
4. **P3 diagnostics/provider split:** profiler, logging, ECS provider, jobs/loading APIs.
5. **P4 generated/external policy:** exclude generated bindings from LOC gate or wrap them behind small public modules.
