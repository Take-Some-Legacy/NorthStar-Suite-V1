# North Star Tools icons

These `.ico` files are Windows multi-resolution application icons generated from the uploaded 1254x1254 PNG source art.

Required layers per `.ico`:

```text
16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256
```

Do not replace them with a single 32x32/64x64 layer. Windows Explorer, taskbar, Start Menu and high-DPI displays choose different icon layers; missing high-resolution layers make the executable icon look blurry or pixelated.
