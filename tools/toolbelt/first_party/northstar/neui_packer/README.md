# North Star NEUI Packer

XML-first .neui UI dictionary packer/inspector/validator.

## Execute-ready binary

```text
bin/northstar-neui-packer.exe
```

## Source

```text
tools/toolsSrc/neui_packer
```

## Common usage

```bat
.\bin\northstar-neui-packer.exe --help
```

This package is first-party North Star tooling. The Suite discovers it recursively through `tool.json`; no per-tool hardcode should be required for generic build/run/list operations.
