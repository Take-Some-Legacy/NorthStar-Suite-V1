# North Star First-Party Toolbelt

This directory contains first-party North Star tools packaged for descriptor-first discovery and local proof-of-work testing.

## Test contract

Every tool package should provide:

```text
<tool>/
  tool.json
  README.md
  bin/<tool>.exe
  test/
    test.bat
    _out/              generated by test.bat; ignored as runtime output
  testData/
    README.md
    proof-input.txt    small deterministic input marker for smoke/proof runs
```

Run all first-party smoke/proof checks from this directory:

```bat
testAll.bat
```

`testAll.bat` writes the aggregate proof log to:

```text
.testAll/last-run.txt
```

Each individual `test/test.bat` writes its own proof files to:

```text
<tool>/test/_out/help.txt
<tool>/test/_out/proof-of-work.txt
<tool>/test/_out/last-run.txt
```
